# Game Plan

## Goal

Focus on making the game feel complete, clear, and well-paced before adding backend infrastructure.

## Milestone 1: Progression Polish (Done)

1. Refine the level map visuals so it feels authored, not just functional.
2. Make the current level path clearer in the map.
3. Show best stars more prominently on completed levels.
4. Add world completion states and summaries.
5. Give 3-star levels a stronger "perfect" visual treatment.

## Milestone 2: Success Loop (Done)

1. Make win states more rewarding and legible.
2. Add a clearer next-level call to action after success.
3. Explain star awards more clearly.
4. Show personal best versus ideal more cleanly.

## Milestone 3: Curriculum Pass (Done)

1. Audit the first 20-30 levels for pacing.
2. Check that each mechanic has:
   - introduction
   - reinforcement
   - combination
   - mastery
3. Remove weak standalone worlds and awkward transitions.
4. Fill gaps where mechanics appear too abruptly.

## Milestone 4: More Content (In Progress)

1. Add levels only where they support the teaching arc.
2. Prioritize worlds that deepen:
   - procedures
   - toggle timing and ordering
   - multi-step planning
3. Avoid filler puzzles.

## Milestone 5: Game Feel

1. Improve level-to-level transitions.
2. Clean up success and failure animation timing.
3. Add more intentional robot and board feedback.
4. Add sound only if it supports the game feel clearly.

## Milestone 6: Progression Data

1. Persist more completion-quality data locally when useful.
2. Consider storing:
   - best program size
   - perfected levels
   - world completion summaries
3. Keep this in localStorage for now.

## Not Now

1. Backend auth
2. Accounts
3. Cloud saves
4. Social features
5. Reintroducing a hints system

## Recommended Next Build

### First

1. Improve the level map visuals.
2. Persist best program size.
3. Show best versus ideal in the level map for completed levels.
4. Add stronger world completion summaries.
5. Make 3-star levels feel special.

### Then

1. Review all worlds.
2. Merge or thin weak sections.
3. Add missing mechanic-teaching levels.
4. Smooth difficulty spikes across the campaign.
